# Phoenix DLSS5 1.0 validation

The addon and helper are rebuilt with the stable version identity. The release checks bind the built binaries to their source, exercise CPU and software D3D12 contracts, and verify x86/x64 DLL loading, embedded resources and downloadable archives. See the release's VALIDATION.json for exact checks and SHA-256 identities.

The standalone native library, kernels and optional Input companion retain the already qualified Beta 2 bytes. Earlier GPU and game runs retain their original build identities. Older RTX routes remain experimental.
