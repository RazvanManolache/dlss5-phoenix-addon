# Phoenix 1.1.6 validation

- The new rendering regression reproduced the previous rejection before the fix and passed after it.
- Eight software D3D12 cases exercise the real color conversion, appearance, scaling and output shaders with Original and Lightweight FP8 selected: legacy super resolution and explicit working scales of 96%, 150% and 100%. Neural inference uses a model-free passthrough executor. Checks verify style application, finite output, preserved alpha and fence retirement.
- Mismatched engine-supplied maps remain rejected before the renderer records their processing work.
- Both x86 and x64 UI suites verify that Normal, Super resolution and quality buttons update the active canvas without clearing color settings. These extend the existing model, layout, dashboard and control checks.
- Release core builds run 35 CPU suites and six software D3D12 suites. Final package validation checks both addon architectures, DLL loading, exports, embedded payload identities and extraction.

These checks do not establish new live-game, neural-inference, performance or physical older-GPU coverage. Unchanged runtime companions retain their previous validation; release packaging verifies their identities separately. Source archives, binary payloads and public downloads are audited before publication.
