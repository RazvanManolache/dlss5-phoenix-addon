# Phoenix DLSS5 1.0.1 validation

The release checks cover the Windows add-on and helper builds, CPU contracts, software D3D12 capture, x86 and x64 DLL loading, embedded resource extraction, and package integrity. The downloadable `VALIDATION.json` records the individual checks and SHA-256 identities. The previously released inference payload and optional Input companion are retained with their existing evidence.

Retail-game and hardware inference results for previous builds retain their original scope. Older RTX kernels remain experimental.
