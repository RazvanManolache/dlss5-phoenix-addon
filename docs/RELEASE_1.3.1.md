# Phoenix DLSS5 1.3.1

- The optional Windows Phoenix Input companion can target the game executable when a launcher and game share the same addon directory. Only the configured executable opens the input session.
- Phoenix Input follows game viewport changes, forwards messages to the correct window handler, and restores that handler when switching away.

See the [Phoenix Input setup guide](PHOENIX_INPUT.md) for the `target_executable` option and [validation details](VALIDATION_1.3.1.md) for the test scope.
